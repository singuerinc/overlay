# Overlay

## Install from NPM

```
pnpm add @singuerinc/overlay
# or with npm
npm install @singuerinc/overlay
```

## Setup Overlay

```tsx
// import Overlay
import { Overlay } from "@singuerinc/overlay";
// import Overlay styles
import "@singuerinc/overlay/overlay.css";

// place Overlay anywhere inside the body
<body>
    <!-- your app -->
    <Overlay />
</body>
```
